# Proposed repository-wide license

Status: awaiting the owner's choice. This document is a proposal, not an operative license grant for the application.

The Solidity sources already declare `SPDX-License-Identifier: MIT`. The repository has no root software license covering its Python and TypeScript code. MIT is the proposed choice for consistent licensing of original project code. The owner must choose and approve the repository-wide terms before this proposal is installed as `LICENSE`.

The text below uses GitHub's [MIT template](https://github.com/github/choosealicense.com/blob/gh-pages/_licenses/mit.txt), with the proposed copyright holder filled in for review. Existing third-party notices and source-data licenses remain separate. Adopting a software license does not relicense the retained UK-AIR or AirNow source data.
